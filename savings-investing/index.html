Common questions

How is compound interest calculated?

Each period's interest is added to the balance before the next period is worked out, so growth compounds: A = P(1 + r/n)^(nt). The calculator shows the year-by-year breakdown so you can see it building.

Is CAGR the same as average annual return?

No. A simple average ignores compounding and overstates growth after volatile years; CAGR is the single smoothed rate that takes the start value to the end value.

Do these account for UK tax?

They work in gross figures. For VAT or income-tax bands use the Tax / VAT calculator.
