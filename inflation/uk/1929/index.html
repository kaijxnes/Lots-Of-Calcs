Frequently asked questions

How much is £100 from 1929 worth today?

About £9,355 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1929 would cost £9,355 now if its price had risen in line with inflation.

How much have prices gone up since 1929?

By 9255.1% in all, an average of 4.8% a year.

What would £100 today have been worth in 1929?

£1.07. Today's money buys that much less than the same amount did in 1929.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
