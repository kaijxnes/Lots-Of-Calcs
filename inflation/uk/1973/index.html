Frequently asked questions

How much is £100 from 1973 worth today?

About £1,781 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1973 would cost £1,781 now if its price had risen in line with inflation.

How much have prices gone up since 1973?

By 1681.0% in all, an average of 5.6% a year.

What would £100 today have been worth in 1973?

£5.61. Today's money buys that much less than the same amount did in 1973.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
