Frequently asked questions

How much is £100 from 1932 worth today?

About £10,279 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1932 would cost £10,279 now if its price had risen in line with inflation.

What would £100 today have been worth in 1932?

£0.97. Today's money buys that much less than the same amount did in 1932.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
