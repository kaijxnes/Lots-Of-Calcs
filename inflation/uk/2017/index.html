Frequently asked questions

How much is £100 from 2017 worth today?

About £139.36 in September 2026 money, using the Consumer Prices Index (CPI). Something that cost £100 in 2017 would cost £139.36 now if its price had risen in line with inflation.

How much have prices gone up since 2017?

By 39.4% in all, an average of 3.7% a year. The RPI, which usually runs higher, puts it at 54.9%.

What would £100 today have been worth in 2017?

£71.76. Today's money buys that much less than the same amount did in 2017.

Which inflation measure is used?

The Consumer Prices Index (CPI) from the Office for National Statistics, the official UK measure since 1996, using each year's average and the latest month published. CPI figures start in 1988; earlier years use the ONS long-run RPI series.
