Frequently asked questions

How much is £100 from 1918 worth today?

About £8,368 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1918 would cost £8,368 now if its price had risen in line with inflation.

How much have prices gone up since 1918?

By 8267.8% in all, an average of 4.2% a year.

What would £100 today have been worth in 1918?

£1.20. Today's money buys that much less than the same amount did in 1918.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
