Frequently asked questions

How much is £100 from 1919 worth today?

About £7,604 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1919 would cost £7,604 now if its price had risen in line with inflation.

How much have prices gone up since 1919?

By 7503.7% in all, an average of 4.1% a year.

What would £100 today have been worth in 1919?

£1.32. Today's money buys that much less than the same amount did in 1919.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
