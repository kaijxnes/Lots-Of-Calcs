Frequently asked questions

How much is £100 from 1920 worth today?

About £6,582 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1920 would cost £6,582 now if its price had risen in line with inflation.

How much have prices gone up since 1920?

By 6481.8% in all, an average of 4.0% a year.

What would £100 today have been worth in 1920?

£1.52. Today's money buys that much less than the same amount did in 1920.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
