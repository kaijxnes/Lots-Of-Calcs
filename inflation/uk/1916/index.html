Frequently asked questions

How much is £100 from 1916 worth today?

About £12,809 in September 2026 money, using the long-run Retail Prices Index. Something that cost £100 in 1916 would cost £12,809 now if its price had risen in line with inflation.

How much have prices gone up since 1916?

By 12709.2% in all, an average of 4.5% a year.

What would £100 today have been worth in 1916?

£0.78. Today's money buys that much less than the same amount did in 1916.

Which inflation measure is used?

The ONS long-run Retail Prices Index series, which goes back to 1800, as CPI figures only start in 1988. RPI tends to run a little higher than CPI.
