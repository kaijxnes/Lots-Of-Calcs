Frequently asked questions

How much is £100 from 2015 worth today?

About £144.10 in September 2026 money, using the Consumer Prices Index (CPI). Something that cost £100 in 2015 would cost £144.10 now if its price had risen in line with inflation.

How much have prices gone up since 2015?

By 44.1% in all, an average of 3.3% a year. The RPI, which usually runs higher, puts it at 63.3%.

What would £100 today have been worth in 2015?

£69.40. Today's money buys that much less than the same amount did in 2015.

Which inflation measure is used?

The Consumer Prices Index (CPI) from the Office for National Statistics, the official UK measure since 1996, using each year's average and the latest month published. CPI figures start in 1988; earlier years use the ONS long-run RPI series.
