Common questions

What's the difference between the basic and scientific calculator?

The basic calculator covers the four operations, percentages and memory keys — everything a desk calculator does. The scientific one adds trig functions, logarithms, powers, roots and a DEG/RAD toggle for anything past arithmetic.

Can these handle recurring decimals?

Yes — the decimal ↔ fraction converter detects recurring digits (like 0.333…) and converts them to an exact fraction rather than rounding, which most converters get wrong.

Is the percentage calculator the same as the one for percentage change?

One tool covers all three: X% of Y, X as a percentage of Y, and the percentage change between two values — so you don't need to remember which formula applies.
